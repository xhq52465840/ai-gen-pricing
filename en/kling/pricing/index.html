What to know before you pay

  • Kling’s API price list is in units with a dollar figure next to each (for example Kling 3.0 at 1080p without audio: 0.8 units, $0.112 per second). Source
  • On 28 Oct 2026 the Kling 4.0 rows were still labelled “Coming Soon” preview prices on Kling’s own API page, while fal, Replicate and Runway already sell it at the same $0.157 and $0.235 per second. Source
  • The kling.ai app sells credit memberships, but we found no official public table of app credits per model, so only API prices are listed. Source
