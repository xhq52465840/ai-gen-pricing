Privacy policy

Last updated: 28 Oct 2026

GenCost is a static website. It has no accounts, no forms and no cookies of its own, and the calculator runs entirely in your browser; nothing you type is sent to us.

The site is hosted on GitHub Pages. GitHub may log technical data such as your IP address to run and secure the service; see GitHub’s privacy statement.

Links to platforms are plain links. If we ever add affiliate links or ads, we will label them and update this page first.

Questions: open an issue on the GitHub repository linked in the footer.
