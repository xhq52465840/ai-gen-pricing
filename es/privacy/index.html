Política de privacidad

Última actualización: 28 oct 2026

GenCost es un sitio web estático. No tiene cuentas, formularios ni cookies propias, y la calculadora funciona entera en tu navegador; nada de lo que escribes se nos envía.

El sitio está alojado en GitHub Pages. GitHub puede registrar datos técnicos como tu dirección IP para prestar y proteger el servicio; consulta la declaración de privacidad de GitHub.

Los enlaces a las plataformas son enlaces normales. Si algún día añadimos enlaces de afiliado o anuncios, los señalaremos y actualizaremos antes esta página.

Dudas: abre una incidencia en el repositorio de GitHub enlazado en el pie de página.

GitHub Privacy Statement
