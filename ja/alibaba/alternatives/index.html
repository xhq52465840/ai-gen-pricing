Alibaba Cloud Model Studio (Wan)の代替サービス

クレジットプランの実効単価は、1クレジットあたり最も安いプラン（年払いがあれば年払い）で計算しています。下の小さい数字は最小プランを月払いした場合です。

代替を探す理由

使えるクリップ1本あたりの価格、期限切れになるクレジット、速度制限される「無制限」、失敗・ボツになった出力への課金。1〜2個のモデルしか使わないなら、使い切れないクレジットプランより従量課金APIのほうが安いことが多いです。
