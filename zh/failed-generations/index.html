失败的生成要花你多少钱

标价是按“生成一次”算的，不是按“能用的成片”算的。有两种情况会让你多花钱：出错（任务失败或被拦截）和废片（生成完了，但脸变了、文字错了或动作不对，只好重跑）。

怎么算

每个可用输出的真实价格 = 标价 ÷ 保留率。两条留一条就是付两倍，四条留一条就是四倍。平台退还积分的报错不算，但废片永远要算。

例子：Kling 4.0 1080p 走官方 API 是每秒 0.235 美元，一条 5 秒视频 1.18 美元。如果三条只留一条，你发布的每条视频成本就是 3.53 美元。

各平台的规则

  • 生成失败时积分通常会自动退回。已经完成的生成不退积分，即使你不满意结果。 来源
  • 首次购买后 3 天内，符合条件的订阅积分可以退款。 来源
  • 加购积分不过期，订阅结束后也能用，但不能退款。 来源
  • 额外算力包是一次性购买，90 天后过期。 来源
  • 也卖预付资源包，不能退款，购买 90 天后过期。 来源
  • Standard 和 Pro 的积分每月清零；Max 可以把最多一个月没用完的积分结转。额外购买的积分永不过期。 来源
  • Premium+ 及以上套餐对部分模型（包括 Nano Banana 2 和 Nano Banana Pro）不限次数，这些模型多生成一张不再额外花钱。 来源
  • Runway: 每次生成最低 80 积分 (Seedance 2.5), 每次生成最低 56 积分 (Seedance 2.0). 来源

怎么少浪费

  • 先便宜地打草稿，再贵地出成片：用 480p 或 Fast/Lite 版本测试提示词，选中后再用全画质生成。
  • 用能满足需要的最短时长生成；大多数视频模型按秒计费。
  • 先把图定下来：用一张好的静帧做图生视频，比纯文字生视频的废片率低。
  • 跑批量之前，先确认被审核拦截的任务收不收费。
