Início / Privacidade

Política de privacidade

Última atualização: 28 out 2026

O GenCost é um site estático. Não tem contas, formulários nem cookies próprios, e a calculadora roda toda no seu navegador; nada do que você digita é enviado para nós.

O site é hospedado no GitHub Pages. O GitHub pode registrar dados técnicos, como seu endereço IP, para operar e proteger o serviço; veja a declaração de privacidade do GitHub.

Os links para as plataformas são links comuns. Se um dia adicionarmos links de afiliado ou anúncios, vamos identificá-los e atualizar esta página antes.

Dúvidas: abra uma issue no repositório do GitHub indicado no rodapé.

GitHub Privacy Statement
